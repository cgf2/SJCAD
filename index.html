操作说明

基本手势

  • 单指点按：拾取 / 确定点位
  • 单指拖动：框选（选择工具）/ 执行拉伸、移动、旋转
  • 双指拖动：平移视图；双指捏合：缩放视图
  • 选择模式下双击空白：全图自适应
  • 右侧 ✥ 进入临时平移模式

精度输入

直线：输入起点 / 终点坐标；圆：输入圆心坐标与半径；点：输入 X / Y；平行线：先点参考线，再输入偏移距离。非法数值会标红并提示。

正交与多选

直线工具打开“正交”后只能绘制 0°/90°/180°/270° 方向；平移工具打开“连续选择”后可点选多个图形，输入 X/Y 偏移一次平移。

等距线与坐标点

等距线可输入距离并选择左侧/右侧/双侧：单侧只生成一条完整等距线，双侧各生成一条，结果不会重复叠加；可对选中对象批量生成。查询页“坐标点”连续点选端点、中点、交点、圆心等，自动汇总坐标列表。

阵列与连续选择

编辑页“阵列”先选图形，再选阵型：矩形填写行数、列数、行距、列距；环形填写数量（含源对象）与总角度（默认 360° 整圈等分，非整圈按数量等分角度）。环形默认绕选中对象包围盒中心旋转，打开“自定义圆心”后可输入圆心 X/Y，或直接点按画布空白处拾取圆心。画布实时虚线预览，确定后生成副本；“选择”工具可打开“连续选择”逐个累加/取消选中（框选为追加），再打开“关联选择”可自动带出端点相连的图形。

圆弧过渡

编辑页选择“圆弧过渡”，依次点按两条相交或相邻的线段，设置半径后点“确定”，自动生成相切圆弧并保留两条线段可编辑。

属性编辑

查询页“属性”面板中的坐标、半径、角度可直接修改，画布实时同步，可撤销 / 重做。

脚本

右上角 </> 打开脚本控制台，每行一条命令，支持 line / circle / arc / point / angle / clear。
