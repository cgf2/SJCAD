操作说明

基本手势

  • 单指点按：拾取 / 确定点位
  • 单指拖动：框选（选择工具）/ 执行拉伸、移动、旋转
  • 双指拖动：平移视图；双指捏合：缩放视图
  • 选择模式下双击空白：全图自适应
  • 右侧 ✥ 进入临时平移模式

精度输入

直线：输入起点 / 终点坐标；圆：输入圆心坐标与半径；点：输入 X / Y；平行线：先点参考线，再输入偏移距离。非法数值会标红并提示。

正交与多选

直线工具打开“正交”后只能绘制 0°/90°/180°/270° 方向；平移工具打开“连续选择”后可点选多个图形，输入 X/Y 偏移一次平移。

等距线与坐标点

等距线可输入距离并选择左侧/右侧/双侧：首尾相连的直线与圆弧会按整条链偏移，拐角自动斜接，双侧生成内外两圈且不会出现交叉、勾形或断口；结果不会重复叠加，可对选中对象批量生成。查询页“坐标点”连续点选端点、中点、交点、圆心等，自动汇总坐标列表。

圆心与交点捕捉

画圆、画点或绘制直线时，靠近已有圆 / 圆弧的圆心会自动吸附，并以圆圈 + 十字标记和“圆心”标签提示；靠近两条图元的交点时同样吸附，并显示“交点”标记，便于以交点作为圆心或起点。点工具在圆周附近点按会直接生成圆心点。直线绘制过程中经过圆 / 圆弧时参数区自动出现“相切”开关，开启后生成切线；经过直线时自动出现“垂直”开关，沿垂线方向生成。确定起点后，终点会自动捕捉：靠近圆弧吸附切点、靠近直线吸附垂足，画布显示“捕捉切点 / 捕捉垂足”标记，状态栏同步显示当前捕捉类型；端点、中点、交点、圆心等标准捕捉优先，互不冲突。捕捉阈值可在参数区选择（12 / 18 / 24 / 36px），按 F3 切换捕捉开关、按住 Shift 临时关闭。

圆弧与平行线

“圆弧”为两点 + 半径：依次点按两个端点，输入半径后确定，可在“弧向”中切换劣弧 / 优弧；半径小于弦长一半时自动按半圆生成。平行线可在基准线任意一侧点按生成，也可输入偏移距离并选择左 / 右 / 双侧后确定。

阵列、镜像与连续选择

编辑页“阵列”先选图形，再选阵型：矩形填写行数、列数、行距、列距；环形填写数量（含源对象）与总角度（默认 360° 整圈等分，非整圈按数量等分角度）。环形默认绕选中对象包围盒中心旋转，打开“自定义圆心”后可输入圆心 X/Y，或直接点按画布空白处拾取圆心。画布实时虚线预览，确定后生成副本。“镜像”先点选图形，再直接点按一条直线作为镜像轴，立即完成镜像（无需再点确定），原图保留并生成对称副本；也可关闭“点按轴线”改用输入的轴端点坐标。“选择”工具可打开“连续选择”逐个累加/取消选中（框选为追加），再打开“关联选择”可自动带出端点相连的图形。

圆弧过渡

编辑页选择“圆弧过渡”，依次点按两条相交或相邻的直线 / 圆弧（直线-直线、直线-圆弧、圆弧-圆弧均可），设置半径与“裁剪”开关后点“确定”，自动生成相切圆弧并在接点处无缝衔接；开启裁剪会收缩原图形，关闭则保留原图形仅新增过渡弧。

属性编辑

查询页“属性”面板中的坐标、半径、角度可直接修改，画布实时同步，可撤销 / 重做。

脚本

右上角 </> 打开脚本控制台，每行一条命令。新建：line / circle / arc / point / angle / clear；修改画布内已有图形（序号从 1 开始）：set 序号 参数 值（如 set 1 x2 150）、move 序号 dx dy、del 序号。修改后会立即刷新画布与属性面板，并可通过撤销恢复；参数非法时整条命令不写入。
