操作说明
点击任意说明框可查看该功能的完整描述、使用场景与注意事项；也可随时点击画布左上角的绿色功能名称徽标，查看当前功能的操作步骤与完整说明

基本手势

页面初始化时画布中会自动绘制一个圆心位于原点 (0, 0)、直径 100 的圆，并在圆心显示十字中心标记，可直接用于选择、编辑与阵列等操作。

  • 单指点按：拾取 / 确定点位
  • 单指拖动：框选（选择工具）/ 执行拉伸、移动、旋转
  • 双指拖动：平移视图；双指捏合：缩放视图
  • 选择模式下双击空白：全图自适应
  • 右侧 ✥ 进入临时平移模式

取消与操作选项

右侧视图按钮组顶部的“取消”按钮可立即终止当前未完成的手势或绘制，清除选择、测量与临时预览，并回到初始可选择状态。提示条右侧的 ▾ 按钮用于折叠 / 展开当前工具的操作选项；切换工具时选项默认折叠，只有主动点击 ▾ 才会展开，避免自动弹出遮挡画布。

精度输入

直线的“坐标输入”默认关闭：在操作选项中勾选后，才会显示起点 / 终点坐标与“确定”按钮并按坐标精确建线；未勾选时仅支持点按绘制。终点输入提供“绝对坐标 / 增量坐标”两种方式，默认增量坐标（输入相对起点的 ΔX / ΔY）；编辑坐标时画布实时预览即将生成的直线并标注终点坐标，非法数值或起点终点重合会标红并禁止确定。圆：输入圆心坐标与半径或直径；点：输入 X / Y；平行线：先点参考线，再输入偏移距离。非法数值会标红并提示。

半径 / 直径切换

圆工具参数区的“尺寸方式”可在半径 / 直径间切换：切换时面板数值自动换算（如半径 50 ↔ 直径 100），圆的大小保持不变，绘制流程不中断；画布预览与面板标签同步显示 R / ⌀ 及当前输入方式。

正交与多选

直线工具打开“正交”后只能绘制 0°/90°/180°/270° 方向；平移工具打开“连续选择”后可点选多个图形，输入 X/Y 偏移一次平移。

平移到指定坐标

平移工具操作面板内的“移动到”开关默认关闭，此时保持原有拖动 / X-Y 偏移平移逻辑。开启后按三步操作：先点按图形选择要移动的元素；再在画布上点按拾取基准点（仅支持鼠标 / 手指点选，自动吸附端点、中点、圆心、交点，无需也不能输入参考点坐标）；最后确定目标位置，可任选两种方式——直接在画布上点按目标位置，或在面板“目标坐标”中输入目标 X / Y 后点“确定”。两种方式并行可用、可随时切换，移动完成后基准点自动复位、目标坐标回填到面板，面板提示条会随步骤同步显示当前应做的操作。多选时以整体包围盒随基准点一起平移，图形数量与形状保持不变。再次关闭开关即回到偏移平移模式；目标坐标为空、未拾取基准点、未选中图形或基准点已在目标位置时都会给出提示且不会产生错误位移。移动到模式下拖动画布只平移视图，不会误移动图形。

等距线与坐标点

等距线可输入距离并选择左侧/右侧/双侧：首尾相连的直线与圆弧会按整条链偏移，拐角自动斜接，双侧生成内外两圈且不会出现交叉、勾形或断口；结果不会重复叠加，可对选中对象批量生成。查询页“坐标点”连续点选端点、中点、交点、圆心等，自动汇总坐标列表。

圆心与交点捕捉

画圆、画点或绘制直线时，靠近已有圆 / 圆弧的圆心会自动吸附，并以圆圈 + 十字标记和“圆心”标签提示；靠近两条图元的交点时同样吸附，并显示“交点”标记，便于以交点作为圆心或起点。点工具在圆周附近点按会直接生成圆心点。直线绘制过程中经过圆 / 圆弧时参数区自动出现“相切”开关，开启后生成切线；经过直线时自动出现“垂直”开关，沿垂线方向生成。确定起点后，终点会自动捕捉：靠近圆弧吸附切点、靠近直线吸附垂足，画布显示“捕捉切点 / 捕捉垂足”标记，状态栏同步显示当前捕捉类型；端点、中点、交点、圆心等标准捕捉优先，互不冲突。捕捉阈值可在参数区选择（12 / 18 / 24 / 36px），按 F3 切换捕捉开关、按住 Shift 临时关闭。

连续画线与圆弧方向吸附

直线工具打开“连续画线”后，每完成一条直线会自动以当前终点作为下一条直线的起点，可连续绘制首尾相连的折线；按 ESC 或右键点击画布退出连续画线并取消未完成的直线。同时开启“坐标输入”时，新直线的起点自动记录为上一条已完成直线的终点（面板起点数值同步更新），只需输入终点坐标并确定即可连续绘制；每次生成后终点输入框自动清零，避免沿用上一段数值，直接输入下一段终点即可（清零后再次确定会提示“起点与终点不能重合”，不会误建零长度直线）。当直线起点落在圆 / 圆弧上时，参数区出现“方向吸附”，可切换“法线 / 切线”：启用后终点被约束在过起点的法线或切线方向上，画布同步显示“法线 / 切线”提示。

圆弧与平行线

“圆弧”为两点 + 半径：依次点按两个端点，输入半径后确定，可在“弧向”中切换劣弧 / 优弧；半径小于弦长一半时自动按半圆生成。平行线可在基准线任意一侧点按生成，也可输入偏移距离并选择左 / 右 / 双侧后确定。

角度线

绘图页“角度线”默认参考方向为“与X轴形成角度”，可在“参考方向”中切换为“与Y轴形成角度”。“长度输入”默认关闭：关闭时先点按起点、再点按方向点，按鼠标方向与距离生成；开启后按面板输入长度生成。打开“与指定线形成角度”后，先点按一条已有直线作为角度参考基准，再点按起点与方向点；生成方向为相对参考基准的指定角度，并自动落在鼠标所在侧，避免背向绘制。

中心线

绘图页“中心线”以点划线样式生成对称中心 / 轴线，并按点选对象自动判断：点按圆（含圆内部）或圆弧，自动生成过圆心的水平与垂直交叉中心线；点按两条平行直线，自动生成与两条直线距离相等的平行中心线；点按两条不平行直线，自动生成两条直线夹角的角平分线。也可在空白处依次点按两点，手绘一条中心线。操作选项中“延伸长度”（默认 6）会让中心线两端自动向外伸出，设为 0 则端点与点按位置一致；生成结果支持选择、移动、镜像、旋转、阵列等编辑操作。

阵列、镜像与连续选择

编辑页“阵列”默认使用环形阵型，选好图形后直接点按画布空白处指定圆心，即可立即生成环形阵列：悬停时以当前位置为暂定圆心显示虚线预览与“圆心”十字标记，点按后圆心固定并生成副本（数量默认 6，含源对象；总角度默认 360° 整圈等分，非整圈按数量等分角度）。也可在操作选项中输入圆心 X/Y 后点“确定”。需要矩形阵列时在“阵型”中切换为矩形，填写行数、列数、行距、列距后确定。“镜像”先点选图形，再直接点按一条直线作为镜像轴，立即完成镜像（无需再点确定），原图保留并生成对称副本；镜像轴只能通过点选直线指定，不再提供手动输入轴坐标的入口。“选择”工具可打开“连续选择”逐个累加/取消选中（框选为追加），再打开“关联选择”可自动带出端点相连的图形。

矩形与多边形

绘图页“矩形”支持单指拖动直接框出矩形，也可点按第一个角点后再点按对角点完成；操作选项中可输入起点 X/Y 与宽高精确创建，并切换实线 / 虚线边框以及无 / 蓝 / 绿 / 橙 / 紫五种填充，拖动时实时预览尺寸。绘图页“多边形”默认依次点按顶点，回到起点或点“确定”自动闭合；在“边数预设”中选择 3 / 5 / 6 / 8 并设置半径后，点按中心即可生成正多边形。将“模式”切换为“编辑顶点”后，点按多边形显示顶点，拖动任一顶点即可调整形状，调整导致退化时会自动还原；也可在“属性”面板直接修改每个顶点坐标。

矩形与多边形的变换

矩形与多边形均支持选择、移动、镜像、阵列、属性编辑与端点 / 交点捕捉；旋转 90° 的非整数倍或沿斜轴镜像会自动转换为等效多边形，保证几何关系不丢失。

轮廓线与样条线

绘图页“轮廓线”连续点按即可绘制由直线段组成的轮廓：回到起点或点“确定”结束，轮廓结束方式可选“自动 / 开放 / 闭合”，自动模式下首尾距离在容差内即判定为闭合轮廓。将“模式”切换为“编辑”后可点按节点选中并拖动调整、再次点按同一节点删除，点按线段中间插入新节点；闭合轮廓至少保留 3 个节点、开放轮廓至少 2 个，退化时自动还原。生成的轮廓为普通折线图元，支持选择、移动、镜像、旋转、阵列、属性编辑与相交裁剪，图层顺序与其它图形一致。绘图页“样条线”依次点按节点生成贝塞尔样条，点回起点或开启“闭合”结束；“平滑度”控制控制柄长度（0 为折线感、1 最圆滑）。编辑模式下显示节点与进 / 出手柄，拖动手柄可单独调节曲线走向，拖动节点整体移动该节点及其手柄；样条线支持端点 / 中点捕捉、长度与中点查询，并可与直线、圆、圆弧、矩形、多边形、轮廓线求交点。编辑页另提供“样条编辑”工具：点按样条线后可拖动节点与进 / 出手柄精修曲线，修改“平滑度”后点“确定”应用并重置控制手柄。轮廓线、样条线与样条编辑均随“功能扩展”开关显隐。

圆弧过渡

编辑页选择“圆弧过渡”，依次点按两条相交或相邻的直线 / 圆弧（直线-直线、直线-圆弧、圆弧-圆弧均可），设置半径与“裁剪”开关后点“确定”，自动生成相切圆弧并在接点处无缝衔接；开启裁剪会收缩原图形，关闭则保留原图形仅新增过渡弧。

删除、裁剪与拉伸

编辑页“删除”点按要删除的图形即可移除，删除后与之相关的约束、标注会自动清理，可用撤销恢复。编辑页“裁剪”用于删除线段被其它图形分割后的某一段：点按要删除的线段部分，该线段需与其它图形存在交点，系统按交点切分后只移除点中的那一段，其余部分保留；没有可用交点时会提示“该图形没有可裁剪的相交点”。编辑页“拉伸”用于调整已有图形：拖动直线端点会沿原方向伸缩（另一端固定），拖动圆弧端点可调整弧长（圆心固定），拖动圆可调整半径、拖动点可移动位置；过程中实时预览，松手生效，取消可还原，支持撤销 / 重做。

属性编辑

查询页“属性”面板中的坐标、半径、角度可直接修改，画布实时同步，可撤销 / 重做。

长度 / 角度 / 距离测量

查询页提供三种测量工具。“长度”点按图形测量长度、半径或弧长：直线显示长度、ΔX、ΔY 与倾角；圆显示半径、直径与周长；圆弧显示半径、圆心角与弧长；点显示坐标信息。结果显示在右侧信息面板，并在画布上显示测量标签。“角度”依次点按两条直线，在交点处测量锐角，同时给出补角与交点坐标。“距离”依次点按两个点或位置，显示两点距离、ΔX / ΔY、方位角与起终点坐标。测量结果实时显示，继续点按其它对象会刷新结果；测量操作只读取图形，不修改图形。

智能标注与尺寸驱动

查询页“智能标注”默认处于“自动”模式，按点选对象自动判断标注类型：点按单条直线只做选中（不创建标注、不弹信息框）；在已选中一条直线后再次点按另一条直线，系统自动执行几何关系判断——两条直线平行时生成两条线之间的距离标注，不平行时生成夹角标注；选中直线后点按画布空白处，才为该直线创建线性尺寸。点按圆直接生成 ⌀ 直径标注，点按圆弧生成 R 半径引线标注（同样不自动弹出信息框）。将“标注模式”切换为“角度”后，依次点按两条相交直线或圆弧，即可在交点处生成角度标注（圆弧 / 圆按交点处的切线方向测量）；打开“正交标注”后，线性标注的尺寸线按主方向调整为水平或垂直，标注值取该方向的坐标差：水平为主时取两端点 X 之差，垂直为主时取 Y 之差，斜线按较大分量自动判断主方向，不再显示斜边实际长度；修改该数值会沿主方向移动终点。拖动标注线时，若沿箭头方向拖出标注范围（约 30px），标注方向会自动在水平 / 垂直之间切换，标注值随之按新方向计算；同一次拖动只切换一次，避免边界处来回抖动，松手后方向保持，可再次拖动切回。点按标注中显示的数值文本才会弹出标注信息框，可查看标注类型与对象并修改数值：改直线长度会保持起点伸缩，改圆 / 圆弧数值会同步半径，改平行距离会保持第一条直线不动并平移第二条直线，角度标注可驱动第二条直线绕交点旋转，即“尺寸驱动”，修改过程实时预览且可撤销；面板底部可删除标注。关闭“显示标注”可隐藏全部标注。

标注线拖拽（数值联动）

在查询页“智能标注”下，画布上已生成的标注线可直接拖动：鼠标移到标注线（尺寸线、角度弧、直径 / 半径引线）上会加粗提亮并显示抓手光标，按住左键拖动即可调整标注。拖动时标注值实时联动：线性标注调整与图形的距离、角度标注调整圆弧半径；直径 / 半径标注的箭头始终锚定——一端精确落在圆 / 圆弧轮廓上，另一端固定在圆心，鼠标只改变标注方向，圆弧标注的方向还会被限制在弧范围内。当拖动落点位于圆内部时，自动切换为穿过圆心的完整双向箭头，箭头两端分别指向圆的两侧轮廓；落点在圆外时恢复“圆心→轮廓”的半径样式并用引线放置数值。任意鼠标路径下箭头端点均无偏移或错乱，松手后自动保存并提示“标注线位置已更新”。跟随为实时逐帧刷新，快速或慢速移动都不会出现跳动、偏移或延迟。拖拽仅在查询模块生效，不影响选择、绘图等其它工具；调整后的位置会随查询刷新保持，撤销 / 重做可恢复。单击标注线本身不会打开信息框（只用于拖拽定位），仅当鼠标点按标注中显示的数值文本时才会弹出标注信息框修改数值；悬停数值时显示可点击光标。拖动中按 ESC 或切到双指缩放会取消并回到原位置。

平行距离标注

将“标注模式”切换为“平行距离”后，依次点按两条平行直线，或直接拖动框选两条平行线段，即可生成平行距离标注。系统自动校验平行关系：两条线段夹角超过约 0.57° 会提示“两条线段不平行，无法标注平行距离”，重合线段提示距离为 0；选中的不是直线时也会明确提示，框选数量不是两条时提示当前框选数量。标注自动计算两条平行线的最短垂直距离：尺寸线严格垂直于两条线、两端箭头分别指向两条线，并在两端绘制沿平行方向的延伸定位线；当两条线段在方向上的投影没有重叠（延长线平行）时，自动取最近端点之间的有效平行区间定位，并用细虚线补齐未覆盖的线段部分，保证读数准确。标注风格与其它智能标注一致，右侧面板可自定义标注文字字体、字号、文字颜色与尺寸线实线 / 虚线；面板中的“距离”输入框可直接修改距离值：第一条直线保持不动，第二条直线沿法线平移，使垂直距离精确等于输入值（尺寸驱动，可撤销）；拖动尺寸线只会沿平行方向调整显示位置，不改变距离数值；面板底部可删除标注。

几何约束

“约束”页提供水平、垂直、对称、共线、相切、距离、平行、固定、角度、点在线上、重叠、重合、端点重合十三类约束，添加后图形会保持该关系：之后修改属性、移动或再次点按约束都会重新求解。水平 / 垂直点一条直线即可（保持起点与长度）；对称依次点两个同类图形和一条对称轴；共线先点基准直线，再连续点其它直线 / 点 / 圆，点“确定”结束；相切点两个圆、圆弧或圆与直线；距离点两个点 / 图形后按面板距离固定间距（直线取中点、圆取圆心）；平行点两条直线；固定点一个图形使其在后续求解中保持不动，操作选项可勾选“仅固定端点”，此时只锁定直线两端点、圆弧起止点、矩形 / 多边形角点或圆心，形状与方向仍可调整；角度点两条直线后按面板角度（0~180°）固定夹角；点在线上点一个点 / 圆 / 圆弧再点一条直线（圆自动取圆心）。鼠标悬停即可看到约束后的虚线预览，画布以 H / V / ⇋ / ≡ / T / ↔ / ∥ / ⚓ / ∠ / ⌖ / ⧉ / ⊙ 标记显示约束。在“约束管理”中可查看全部约束、点行高亮对应图形、直接修改距离 / 角度 / 重叠比例或删除约束；删除图形后相关约束自动清理。

批量对齐与等长约束

约束页内置“水平对齐”“垂直对齐”“等长”三个工具，无需额外配置：选中工具后点按或框选两个及以上图形，点“确定”即可一键套用。水平对齐以第一个可测图形的代表点为基准，将其余图形沿 Y 方向平移对齐；垂直对齐同理沿 X 方向对齐；等长以第一条直线长度为基准，其余直线绕各自中点缩放至等长（不支持直线的图形会提示并跳过）。应用后若偏差已小于 2 像素误差，会提示“已在 2px 误差内满足”，约束关系照常建立并保持。约束在画布上以 ⇔ / ⇕ / = 标记显示，标记与文字按实时偏差着色：偏差在 2px 内显示绿色 ✓，超出显示红色 !，便于即时判断约束状态；应用后可继续拖动图形，约束会实时求解保持关系。

点对齐

水平对齐 / 垂直对齐的操作面板新增“对齐方式”切换，默认“边界对齐”（即上述代表点对齐），切换为“点对齐”后可选“对齐点”：左上角、中心点、右上角、左下角、右下角或“指定锚点”。“指定锚点”需输入锚点 X / Y（世界坐标，Y 轴向上），所有选中图形会按该坐标对齐到对应轴。“吸附阈值”默认 5px，可设为 0~50px：应用前偏差在阈值内会提示“已吸附到对齐点”，超过阈值则正常对齐并提示原偏差；无论是否在阈值内，约束都会精确对齐。点对齐会按元素包围盒取点，因此直线、圆、圆弧、矩形、多边形、样条线以及文本框、图片、容器等自定义元素均可使用。选择过程中画布实时显示对齐点标记：第一个图形为橙色“基准”，其余为蓝色标记，并绘制虚线参考线；悬停图形会预览其对齐点。键盘快捷键：1 左上角、2 中心点、3 右上角、4 左下角、5 右下角、0 指定锚点、M 在点对齐与边界对齐之间切换（输入框聚焦时不触发）。点对齐约束在画布上的标记使用 ⇔ / ⇕ 加锚点十字，绿色 ✓ 判定阈值同样取面板设置的吸附阈值。

相对垂直约束

“相对垂直”用于让目标元素按参考元素的垂直位置定位：先点按目标元素，再点按参考元素，然后在操作选项中设置“参考位置”（顶部 / 中部 / 底部）与“垂直偏移”，点“确定”应用。目标元素以其代表点（直线中点、圆 / 圆弧圆心、点本身、矩形 / 多边形 / 样条线包围盒中心）对齐到“参考元素所选位置 + 偏移”的 Y 坐标；偏移为世界坐标，正数向上、负数向下，范围 ±1000000。选择过程中画布显示参考位置虚线、偏移箭头与目标代表点圆环；应用后约束列表显示“相对垂直 顶部 +20”等摘要，画布标记显示 ⇳ 与锚点文字，偏差在 2px 内显示绿色 ✓。目标与参考不能是同一元素；参考元素缺失、锚点非法或偏移超范围时会给出明确提示且不创建约束。删除目标或参考元素后，约束会自动清理。相对垂直与垂直对齐可同时使用，互不破坏原有行为。

重合约束

约束页“重合”用于手动连接两个带端点的图形（直线、圆弧、矩形、多边形、点）：先点按基准图形，再点按另一个图形，系统自动比较两组端点并取距离最近的一对建立重合约束，第二个图形立即平移使该对端点精确重合；之后拖动任一图形，另一端会实时跟随保持重合。圆没有端点，不参与重合约束（可改用相切或点在线上）；两个图形已存在重合约束时会提示并重置，重叠约束与重合约束可同时使用。

重叠约束

重叠约束用于两个矩形、多边形或圆：先点按基准图形，再点按要跟随的图形。面板“重叠方式”选择“完全”时，第二个图形自动对齐到基准图形的包围盒并同步尺寸；选择“比例”时按 1~100% 指定第二个图形覆盖基准图形包围盒的面积比例，自动平移第二个图形，尺寸不足时等比放大，基准图形移动或改尺寸后仍保持该比例。约束管理中可直接修改比例数值；约束标记以 ⧉ 加“完全”或百分比显示。

端点重合与线首尾链接

约束页“约束设置”提供两个默认关闭的开关：“端点自动重合”开启后，两个图元的端点（直线端点、圆弧起止点、矩形角点、多边形顶点、点）距离小于“端点阈值”时自动建立重合约束，之后拖动基准图形，关联端点会实时跟随保持重合；“线首尾自动链接”开启后，连续画线时每完成一条直线都会与上一条直线的端点建立重合约束，拖动或修改前一段时后续线段同步跟随。切换开关会给出操作提示，点“确定”可立即检测一次当前画布；也可在直线工具的连续画线模式下直接开启“线首尾自动链接”。

功能扩展

右上角 ☰ 菜单中“脚本控制台”下方的“功能扩展”开关默认关闭。关闭时自动隐藏不常用功能：绘图页的矩形、多边形、圆弧、等距线、轮廓线、样条线，编辑页的样条编辑，以及“约束”页签及其全部约束工具；开启后全部恢复，原有布局与交互不变。开关状态保存在本地，刷新页面或重启应用后仍会保留；切换时工具栏立即按开关状态重排，不残留、不延迟。若关闭时当前正在使用被隐藏的工具，会自动回到“选择”工具；各工具原有的操作逻辑、参数面板与快捷键均不受影响。

脚本

右上角 </> 打开脚本控制台，每行一条命令。新建：line / circle / arc / point / angle / clear；修改画布内已有图形（序号从 1 开始）：set 序号 参数 值（如 set 1 x2 150）、move 序号 dx dy、del 序号。修改后会立即刷新画布与属性面板，并可通过撤销恢复；参数非法时整条命令不写入。

导入 / 导出

菜单“导出 TXT”会先弹出内容预览，文件为 UTF-8 无 BOM 的纯文本（.txt），内容按字段分行缩进，可直接用手机自带文本编辑器打开查看；点“复制内容”可保存到备忘录 / 文件传输助手，或点“下载文件”保存到浏览器下载目录。手机浏览器（如 QQ 浏览器）有时会把文件存放在自身“下载管理”或私有目录中，文件管理里不易找到；此时用复制内容的方式最稳妥。导入时在菜单中选择“导入 TXT / JSON”并选中文件即可恢复图形，同时兼容此前导出的 .json 文件。
